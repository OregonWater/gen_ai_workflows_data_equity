## Conceptual notes

### Profile-aware update and publication instructions

- feeds: docs/reproducibility-notes
- status: reconciled

The initial proposed instructions conflated routine edits to existing files with adding pages to the profile selections and also implied that both profiles should be rendered after every change. The author identified both distinctions before implementation.

The revised instructions put the routine case first. An existing page already selected by focused is edited once and normally checked with a focused render. The complete build remains a periodic comprehensive check, consistent with the recorded purpose of reducing routine rendering work while retaining full-project review. Suitable complete-build checkpoints include structural profile changes, broad reviews, pages omitted from focused and initial integration of new or moved pages.

New pages require a separate selection and navigation check. Complete includes the existing top-level Markdown patterns; focused remains an explicit publication boundary. Supporting assets are referenced by selected pages rather than normally listed as render targets. Links to focused-omitted Markdown pages continue to route to repository source and are not represented as published site pages.

The publication sequence retains separate authorization for commit, source push and deployment. Publishing uses the already rendered and reviewed focused output with `quarto publish gh-pages --profile focused --no-render`; the complete output remains local.

The author identified a missing step after using the workflow: the instructions said to review focused output but did not explain how. The reproducibility notes now place the repository's read-only static server immediately after focused rendering, give the local site and deck URLs, and explain why serving the existing output is preferable to direct `file://` browsing or a preview process that can render during review. The accompanying checklist covers navigation, changed content, deck behavior, notes, links, search and the public boundary.
